# Presentation Sync

Локальное приложение для Mac, которое синхронно показывает до трёх разных презентаций на трёх экранах. Одна команда «вперёд» или «назад» — в том числе с Bluetooth-кликера — переключает слайд во всех запущенных показах.

PowerPoint не требуется активировать: приложение показывает PDF напрямую. Файлы PowerPoint (`.pptx` и `.ppt`) оно может конвертировать локально через LibreOffice.

## Что умеет

- До 3 презентаций одновременно.
- До 3 подключённых дисплеев.
- Отдельный выбор презентации и дисплея для каждой строки.
- Синхронное перелистывание: вперёд, назад и в начало.
- PDF без дополнительных программ.
- Импорт PowerPoint через бесплатный LibreOffice, без загрузки файлов в интернет.
- Если одна презентация закончилась раньше других, она остаётся на последнем слайде.

## Что понадобится

1. Mac с подключёнными внешними экранами.
2. [Node.js LTS](https://nodejs.org/) — нужен один раз для запуска приложения из исходников.
3. [LibreOffice](https://www.libreoffice.org/) — только если хотите выбирать файлы `.pptx` или `.ppt`. Если презентации уже сохранены в PDF, он не нужен.
4. Кликер, который работает как обычная клавиатура и передаёт `←`, `→` или `Space`.

## Установка

Скопируйте папку `presentation-sync` на Mac — например, в `~/Applications/presentation-sync`.

Откройте приложение **Terminal** и выполните:

```bash
cd ~/Applications/presentation-sync
npm install
npm start
```

При первом запуске `npm install` загрузит нужные компоненты приложения. В дальнейшем достаточно двух последних команд:

```bash
cd ~/Applications/presentation-sync
npm start
```

## Настройка дисплеев в macOS

Подключите все экраны до запуска приложения.

1. Откройте **Настройки системы → Дисплеи**.
2. Выберите режим **Расширить дисплей**, а не «Повтор экрана».
3. Убедитесь, что macOS видит нужные экраны.
4. Запустите Presentation Sync и нажмите **«Обновить экраны»**.

Основной экран Mac можно оставить для панели управления, а для презентаций назначить внешние экраны. При необходимости основному экрану тоже можно назначить презентацию.

## Как провести показ

1. В каждой нужной строке нажмите **«Выбрать файл»** и укажите презентацию.
2. В том же ряду выберите экран, на котором она должна появиться.
3. Повторите для второй и третьей презентации, если они нужны.
4. Нажмите **«Запустить на экранах»**.
5. Не закрывайте и не уводите в фон окно управления на Mac: кликер должен управлять именно им.

Показы откроются полноэкранно на выбранных дисплеях.

### Управление

| Действие | Кликер / клавиатура |
| --- | --- |
| Следующий слайд | `→`, `Space`, `Page Down` |
| Предыдущий слайд | `←`, `Backspace`, `Page Up` |
| Первый слайд | `Home` |
| Остановить все показы | кнопка «Закрыть показы» |

Кнопки управления в самом приложении делают то же самое.

## Презентации PowerPoint

PowerPoint без активации не нужен для показа через это приложение.

- **PDF:** выберите файл сразу.
- **`.pptx` / `.ppt`:** установите LibreOffice. Presentation Sync конвертирует копию файла в PDF локально и затем показывает её.
- Если LibreOffice устанавливать не хочется, в PowerPoint или Keynote выберите «Экспортировать как PDF», после чего откройте полученный PDF в Presentation Sync.

## Важные ограничения

- Один и тот же дисплей нельзя назначить двум презентациям.
- Слайды перелистываются с одинаковым номером. Индивидуальные соответствия вида «5-й слайд первой презентации → 8-й слайд второй» в первой версии не предусмотрены.
- При клике мышью по окну показа фокус может уйти с панели управления; перед работой с кликером снова нажмите на окно Presentation Sync на Mac.
- Приложение рассчитано на локальный показ на одном Mac, а не на трансляцию на другие компьютеры по сети.
